# Step 7 · 关系卡 / 状态 / 风格校准 / 上下文持久化

## 1. 关系卡（默认从记录总结一次）

- `packages/core/src/persona/relationship.ts`：本地规则提取关系类型、她对用户的称呼、用户事实、跨度与置信度。
- 首次启动且数据库已有聊天记录时，`useRelationship` 自动生成一次；导入完成后也会生成。
- 不调用模型，不消耗 token；不读取 holdout。
- 设置 → 关系与称呼：可改关系类型、你的名字、她怎么叫你、关系总结、关于你的事实、重要日期/共同经历/不要提的事。
- Prompt 增加关系段，明确“她怎么称呼用户、你们是什么关系、不要编造未提供的共同经历”。

## 2. 人格卡可编辑

- 保留原有事实逐条移除/补充/回滚。
- 新增“编辑人格卡文字”：整体印象/风格总结、边界（每行一条）。
- 所有修改写入本地加密设置，下一轮对话生效。

## 3. ta 的状态面板

- 入口：聊天菜单「ta 的状态」或设置 → 人格卡 → 调整状态。
- 8 个默认心情标签：开心/平静/低落/烦躁/疲惫/害羞/忙碌/生病。
- 四轴滑杆：心情、精力、亲近、防备；一句状态备注；持续 1 小时/今天/直到改回。
- 存储 `emotion.override`；到期自动恢复；备注进入 prompt。
- 不常驻聊天区，保持界面简洁。

## 4. 主动消息简化

- 主界面只保留：开关、三档欲望（克制/日常/黏人）、自定义、暂停 1 小时/24 小时/恢复。
- 高级设置里：每日/每周上限（**0 = 无上限**）、免打扰开关与起止、最小空闲（**秒**）、检查间隔（**秒**）、欲望系数、触发阈值、连续未回上限。
- 去掉“活跃时段”，避免和免打扰重叠；不再要求 0.95 这类几乎达不到的阈值。
- 真实检查间隔按秒执行，最小 3 秒；高频档最小空闲 10 秒，适合模拟真人随手发消息。
- 仍会消耗 token；默认关闭，并显示预估上限。

## 5. 风格校准（默认关闭）

- 设置 → 风格校准：开启后，右键她的消息才出现「风格校准」；不主动弹出。
- 5 档像不像 + 标签（太长/太短/太客气/太冷淡/用词不像/情绪不对/话题跳/标点表情不对）+ 可选改写。
- 反馈存本机 `style.feedback`，最多 200 条；`styleCalibrationText` 生成下一轮 prompt 的风格约束和改写示例。
- 不因一条反馈重训人格卡；可一键清空。

## 6. 聊天持久化 + 话题上下文

- 新增 `chat_message` 表（SQLCipher）：id、ts、payload（ChatMsg JSON）；启动加载最近 300 条。
- 用户消息、她的回复/分段、主动消息、导入素材、撤回/删除/清空都会同步数据库；重启不再丢当前对话。
- 新增 `conversation.state`（summary/topic/turns）：用最近 8 条生成短摘要，限制长度；Prompt 增加“当前话题 + 先接住上一句”，记忆检索用话题 + 当前输入，避免每轮跳到无关记忆。
- 清空对话时同时清空摘要，避免“记得已删除的对话”。

## 已知限制

- 关系类型是规则推断 + 用户确认，不是 LLM 深度总结；暧昧/单人导出可能不准。
- 上下文摘要是抽取式短摘要，不是完整语义压缩；长对话仍依赖最近 20 条 + FTS 记忆。
- 聊天记录持久化保存图片 dataUrl，数据库会随时间变大；后续可改为媒体文件引用。
- 风格反馈是轻量校准，不会重训人格卡。
