# 常在 0.1.0 内测发布说明

## 这是什么

一个 Windows 本地优先的 AI 陪伴应用：导入微信/QQ 聊天记录，生成 ta 的人格卡，用你自己的模型 API 以 ta 的风格聊天。

## 0.1.0 已包含

- 四步引导（18+ → 导入 → 人格卡 → 模型）
- 5 种聊天记录导入 + 体检报告 + holdout
- 人格卡（风格/事实/参考对话/边界）+ 逐条事实审阅/回滚
- 情绪状态、Arc、Governor、记忆检索、事实锁
- 模型预设/测通/重试、AI 味过滤、已读不回、分段、撤回
- 主动消息（预算/免打扰/通知）
- 加密备份/恢复、启动 PIN、一键销毁
- 消息右键菜单、引用/重新编辑、翻一翻、夜间模式、90 分钟提醒

## 安装

- 未签名 `.exe`（NSIS）；SmartScreen 提示“更多信息 → 仍要运行”。
- 安装后把 `libcrypto-3-x64.dll` / `libssl-3-x64.dll` 放到安装目录（portable 版已带）。
- 仅内测，不要分发给外部用户。

## 已知限制

- 需要自备模型 API Key；模型费用由你承担。
- AI 可能生成不准确内容；不是真人，不代表对方本人。
- 备份包含 DB、key 与素材；恢复后需重启。
- 销毁是文件删除，不承诺 SSD 安全擦除。
- 代码未签名；MSI/自动更新未完成。
