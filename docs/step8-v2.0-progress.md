# V2.0 · 创建方式（MBTI 8 模板 + 自定义人格）

- 日期：2026-11-18
- 版本：V2.0
- 基线：`main` / `c730d54` + 本次 V2.0 改动

## 已完成

### 1. 初始聊天界面三选一

没有可用人格时显示：

- 从聊天记录创建；
- 选一个性格开始；
- 自己写一个。

引导页的导入步骤也增加「没有聊天记录？先选一个性格」，不需要先导入。

### 2. 8 个性格模板

`packages/core/src/persona/presets.ts`：

1. 温柔克制
2. 活泼黏人
3. 理性冷静
4. 嘴硬心软
5. 年上照顾
6. 年下直球
7. 毒舌朋友
8. 安静倾听

每个模板包含：

- 句长/语气词/表情/主动性；
- 3 段参考对话；
- 默认事实；
- 固定安全边界；
- 默认关系卡（朋友，用户可改）。

选择后可预览 3 句，支持「就用这个」和「继续微调」。

### 3. 结构化自定义人格

不直接编辑裸 system prompt，而是表单：

- 身份/关系/语气/句子长度；
- 主动程度/表情比例；
- 口头禅/喜欢/不喜欢；
- 边界；
- 可选高级 prompt 后缀（安全规则不可覆盖）。

预览 3 句后创建。

### 4. 统一 PersonaProfile

- 新增 `origin = distilled | preset | custom`；
- 三种创建方式共用人格卡、聊天、情绪、记忆、主动消息；
- 预设/自定义不依赖聊天记录，`useChat` 不再要求 `source.her_messages > 0`；
- 人格卡标题能区分「预设人格 / 自定义人格 / 蒸馏人格」。

### 5. 创建后体验

- 清空演示对话；
- 用模板/自定义的问候语作为 ta 的第一条消息；
- 关系卡写入默认值，可在设置中修改；
- 进入现有聊天界面。

## 已知限制

- 8 个模板是风格模板，不是心理诊断；
- 自定义表单不调用模型生成，预览来自内置示例；
- 预设人格的事实/参考对话是合成内容，用户可继续编辑；
- 创建后默认关系为「朋友」，需要用户自行改成情侣/亲人等；
- 图片理解、语音、形象、桌宠仍属于 V2.1+。
