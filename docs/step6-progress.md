## 手动测试

1. `scripts\dev.ps1`；首次会出四步引导，勾 18+ → 导入 `examples/` → 看人格卡 → 填模型 Key → 进入；
2. 右键任意消息：复制/删除；她的消息可撤回；
3. 设置 → 安全与备份：输入 6 位口令导出 `.czbak`，再恢复（会提示重启）；
4. 输入「删除」测试销毁（**会真的删本机数据，先备份**）；
5. 23:00 后看夜间样式；把系统时间调到深夜或临时改代码验证。
