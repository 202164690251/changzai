# veyrimi · 如晤 · 用户协议（草案 v0.1）

> 内测草案，正式发布前需律师审阅。

1. **产品性质**：如晤是一个本地运行的 AI 聊天模拟工具。所有回复由你配置的模型生成，不是真人，也不代表聊天记录中的对方本人。
2. **使用前提**：你已年满 18 岁；你拥有所导入聊天记录的合法使用权，并已获得相关方必要授权（如适用）。
3. **禁止用途**：不得用于冒充真人、骚扰、诈骗、未经同意披露他人隐私，或任何违法用途。
4. **模型费用**：模型 API 由你自行申请并付费；费用、额度和服务可用性由对应服务商决定。
5. **风险提示**：AI 可能生成不准确或冒犯性内容；请勿把其当作现实关系、医疗或心理建议。若你处于危机中，请优先联系现实中的亲友、急救或专业机构。
6. **数据责任**：数据只在本机；请自行做好加密备份。因设备丢失、口令遗忘、误删除造成的损失由你自行承担。
7. **免责**：内测版本按“现状”提供，不承诺无错误或持续可用。
