# Step 6 验收清单（DPI / 多屏 / 输入法 / 安装包）

> 状态：2026-11-17。✅ 已实现/已验，⚠️ 代码适配但未实机逐项，⛔ 受外部条件阻塞。

## 1. DPI

| 缩放 | 状态 | 说明 |
|---|---|---|
| 100% | ⚠️ | Tauri 窗口 1280×800；截图与布局正常；未在 100% 显示器逐屏走查 |
| 125% | ⚠️ | 常用环境；CSS 使用 px/rem，未见溢出；未逐屏走查 |
| 150% | ⚠️ | 最小 1024×700 可能触发侧栏折叠；已加 `@media (max-width:1120px/900px)` |
| 200% | ⚠️ | 未测试 |

## 2. 多屏

- 应用使用原生窗口标题栏 + Tauri `center`；拖到副屏未发现坐标绑定逻辑。
- ⚠️ 未在双屏不同缩放组合下实机验收；窗口位置未持久化（每次居中）。

## 3. 中文输入法

- Composer 使用 `compositionstart/end` 与 `nativeEvent.isComposing` 防 Enter 误发送（代码已存在）。
- ⚠️ 未在微软拼音/搜狗/QQ 拼音逐项测试；建议发布前用 3 种输入法各测 10 条。

## 4. 1024×700 小窗

- CSS 在 ≤1120px 缩窄会话列表，≤900px 隐藏会话列表；
- ⚠️ 设置抽屉/引导/安全页在 1024×700 下未逐屏截图走查。

## 5. 安装包

| 项 | 状态 | 说明 |
|---|---|---|
| NSIS `.exe` | ✅ | `release/Changzai_0.1.0_x64-setup.exe`（未签名） |
| MSI | ⛔ | 本机无 WiX Toolset；Tauri 自动下载失败。安装 WiX 3.14 后可 `targets:["nsis","msi"]` 重试 |
| 干净机安装 | ⚠️ | 本机安装/启动通过；未在干净 Win10/11 虚拟机验收 |
