## 一页纸速览

**是什么**：单机、单用户、私密的陪伴应用。导入你和前任的微信聊天记录，蒸馏出"她"，用她当年的语气陪你现在。

**不是什么**：不是数字永生、不是角色扮演游戏、不是心理治疗、不是社交产品、不是时间机器。

**三条不可违背的原则**：
1. 陪伴当下（不是回到过去）
2. 事实不可篡改（只有"已分手"这一状态可被悬置）
3. 伤害必须有界（有来由、有上限、有出口）

**MVP 范围（冻结）**：文字聊天 + 人格蒸馏 + 情绪引擎 + 四层记忆 + 主动消息 + 仿微信 UI + 多模型 API + **Windows / macOS / iOS / Android 四端同时交付**。
**不在 MVP**：本地模型、语音克隆、微信/QQ 接入、云同步、账号系统、内购。

**成功标准**：盲测混淆率 ≥50%、情绪收益 +1.5、负向放大率 <5%、5 分钟内完成首次对话、四端同版本可跑通。

## 已锁定的五个产品决策（v1.1）

| # | 决策 | 对架构/文档的影响 |
|---|---|---|
| 1 | **PC 与移动端同时做，全部联网调 LLM API** | 取消 Python sidecar，全栈 TypeScript；Tauri 2 单代码库覆盖四端 |
| 2 | **不内置 Ollama，只支持 API Key** | 模型层只保留 `OpenAICompat`；删除一切本地推理路径 |
| 3 | **不做订阅，一次性买断** | 删除定价/订阅/内购章节，改为"分发与成本" |
| 4 | **公益定位，用户唯一支出是自己的 API 账单** | 无服务端、无账号、无遥测；年运营成本 <¥3,000 |
| 5 | **不做"重说"，改为微信式"撤回"** | 新增 F17 / T31；撤回后旧句必须从记忆与上下文彻底消失 |

## 给执行 Agent 的启动指令

```
0. 先读 02 第 1-3 章，确认技术基线：TypeScript + Tauri 2 + 纯 API，无 Python、无本地模型、无服务端。
1. 搭建 monorepo：apps/app（React + Tauri 2）、packages/core（纯 TS）、packages/shared。
2. 严格按 02 第 14 章任务卡 T01 → T32 顺序执行，不得跳卡；关键路径见该章末尾。
3. 每张卡交付后对照"验收"列自检，不通过不得进入下一张。
4. Prompt 全部放 prompts/，文件名与文档一致，禁止内联硬编码。
5. core 包内禁止出现 window / fs / fetch / localStorage，外部能力一律走注入接口。
6. 所有 P0 功能必须能追溯到 03-PRD 的 F01–F17 编号。
7. "事实锁""安全阀""AI 标识"不得提供任何关闭开关。
8. 四端必须同版本、同功能；不允许"移动端少一个功能"。
```
