## 手动测试

1. `scripts\dev.ps1`，导入 `examples/`，设置模型并点「测一下」；
2. 发几句，观察：有时秒回、有时慢、有时已读不回；长回复会被拆成多条；
3. 聊天右上角「⋯ → 撤回上一条」；
4. 设置 → 主动消息：开启/点「现在发一条试试」；关窗到托盘后等待通知；
5. 设置 → 本地统计：看 proactive_sent。
