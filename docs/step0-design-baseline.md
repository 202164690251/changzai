> 状态：token 与结构基线已定；**高保真视觉稿尚未冻结**（Step 0 待办）。
> 依据：`02-tech-architecture.md` §12.2 / §12.3、`03-prd.md` §6。

## 1. 设计原则

1. **像微信，但不是微信**：沿用交互语言（左白右绿、浅灰背景、圆角气泡），不复刻 LOGO/图标/字体/素材。
2. **AI 标识不可绕过**：每条她的消息右上角 10px「AI」角标，常驻、不可关闭、不可被主题覆盖。
3. **克制**：不做好友列表、朋友圈、支付、群聊；只做一对一。
4. **节奏优先**：输入中、分段到达、已读是核心体验，不是装饰。

## 3. 窗口与布局

- 默认窗口 `1280 × 800`，最小 `1024 × 700`；支持最大化；标题栏用系统原生（不自绘）。
- 布局：单窗口三段式
  ```
  ┌───────────────────────────────────────────────┐
  │ NavBar 44px   备注名 · 在线状态 · ⋯           │
  ├───────────────────────────────────────────────┤
  │                                               │
  │  MessageList（虚拟滚动，向上加载历史）         │
  │   ┌──────── 时间分隔 ────────┐                │
  │   │  her 气泡（白）    [AI]  │                │
  │   │            me 气泡（绿） │                │
  │   └──────────────────────────┘                │
  │   TypingIndicator（三点）                     │
  ├───────────────────────────────────────────────┤
  │ Composer 56px  表情 · 输入框 · 发送           │
  └───────────────────────────────────────────────┘
  ```

## 4. 组件清单（Step 6 逐条实现）

- `NavBar`：备注名、在线/输入中、`⋯`（人格设置、安全页、退出）
- `MessageList`：虚拟滚动、时间分隔（>5 分钟）、自动贴底、向上加载
- `TextBubble` / `ImageBubble` / `VoiceBubble` / `SystemNotice`
- `AICornerBadge`：10px 角标，`aria-label="AI 生成内容"`，不可被样式覆盖
- `TypingIndicator`：三点动画 1.2s/循环，可被"取消输入"打断（8%）
- `Composer`：多行输入、Enter 发送 / Shift+Enter 换行、表情
- `LongPressMenu`：复制 / 引用 / 撤回 / 删除
- `DoorsEntry`：三扇门入口（日常 / 翻一翻 / 深夜）
- `SafetyPage`：危机资源、时长提醒、降频、退出

## 5. 状态与节奏（验收用）

| 状态 | 表现 |
|---|---|
| 发送中 | 消息先本地入列，右侧小 loading，失败可重试 |
| 她输入中 | 三点动画；可"取消输入"（8%）；最长 6s |
| 分段到达 | 多条间隔 0.6–2.2s；每段独立气泡 |
| 已读 | 未回时显示"已读"；30–90 分钟后可能补一句 |
| 撤回 | 气泡消失 → 系统提示「对方撤回了一条消息」→ 2–6s 后"对方正在输入…" → 新消息 |
| 深夜 | 23:00 后背景变暗、动画变慢；不给建议 |
| 危机 | 退出角色，切中性语气，给求助资源 |

## 6. 文案纪律

- 不用感叹号；不用"亲爱的/用户"；系统提示都用"你"。
- 空状态：「还没有开始」；出错：「她好像没看到」；主动通知：「她发来一条消息」。
- 免责：「她不是真人。但你可以当真一会儿。」
