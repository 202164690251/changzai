# veyrimi · 如晤 · 隐私政策（草案 v0.1）

> 本文件是内测草案，正式发布前需律师审阅。

## 1. 我们收集什么

**不收集。** 如晤是本地优先的 Windows 桌面应用：

- 聊天记录、头像、图片、语音、人格卡、情绪状态、统计数据都只写入你电脑上的本地数据库（SQLCipher 加密）。
- 没有服务器、没有账号系统、没有遥测上传。
- 我们不会收到你的聊天内容、模型 Key 或使用数据。

## 2. 第三方模型

当你配置 OpenAI 兼容模型并发送消息时，应用会把**当前对话上下文**发送到你填写的 Base URL（例如 DeepSeek、OpenAI）。该请求受对应服务商的隐私政策约束。
- 你的 API Key 只保存在本机加密数据库。
- 应用不会把你的数据发往你配置之外的地址。

## 3. 数据删除

- 设置 → 安全与备份 → 导出/恢复/销毁。
- 销毁会删除本机数据库、密钥、图片/语音素材和日志；已删除内容不承诺可恢复（SSD、快照、备份可能保留副本）。
- 换电脑请使用加密 `.czbak` 备份；备份口令由你保管，丢失无法恢复。

## 4. 未成年人

产品仅面向 18 岁以上用户。首次启动会要求确认年龄；请勿让未成年人使用。

## 5. 联系

内测问题请通过 GitHub Issues 反馈；不要在 Issue 里贴真实聊天记录、API Key 或个人信息。
