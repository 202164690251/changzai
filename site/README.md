# 官网（静态）

`site/index.html` 是一个无构建、无追踪的静态下载页，可直接放到 GitHub Pages / Cloudflare Pages / 任意静态托管。

- 下载按钮指向 GitHub Releases；
- 隐私政策/协议/AI 标识链接到 `docs/`；
- 截图引用 `docs/assets/`；
- 不包含任何第三方脚本或统计。

## 发布前

1. 把 `https://github.com/202164690251/changzai/releases` 替换为实际 Release 地址；
2. 上传截图或改成绝对路径；
3. 律师审阅隐私/协议/AI 披露后再公开；
4. 在 GitHub Pages 设置 `site/` 为根目录，或复制到任意静态托管。
